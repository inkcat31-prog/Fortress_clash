# FORTRESS CLASH Beta 2.4 — онлайн-сервер

Цей сервер передає повідомлення між двома браузерами через інтернет. Реальний стан гри обробляє браузер гравця, який створив кімнату; сервер не зберігає акаунти й не потребує бази даних.

## Локальна перевірка на комп'ютері

1. Встанови Node.js LTS.
2. Відкрий термінал у цій папці.
3. Виконай `npm install`, потім `npm start`.
4. Сервер працюватиме на `ws://localhost:3000`.
5. Для перевірки двома вкладками на одному комп'ютері введи цю адресу в обох копіях гри.

`localhost` доступний лише на тому самому пристрої. Для двох телефонів через різні інтернети потрібна публічна адреса `wss://...`.

## Розміщення в інтернеті (наприклад, Render)

1. Завантаж цю папку до нового GitHub-репозиторію.
2. На Render створи **New Web Service** і під'єднай цей репозиторій.
3. Build command: `npm install`.
4. Start command: `npm start`.
5. Після розгортання скопіюй публічну адресу сервісу й заміни `https://` на `wss://`.
6. Відкрий `FORTRESS_CLASH_Beta_2_4.html` на обох телефонах. У режимі «Онлайн-мультиплеєр» введи однакову адресу `wss://...`. Перший гравець створює кімнату й передає шестизначний код другому; другий вводить код і приєднується.

Безкоштовні тарифи можуть засинати або мати інші обмеження. Тоді з'єднання може починатися повільніше.

## Важливо

- Не публікуй секретні ключі чи паролі в HTML.
- Це ранній прототип. Сервер не має системи акаунтів, рейтингу, античіту або відновлення матчу після розриву з'єднання.
- Кімната закривається, якщо від'єднується її власник.
- Для публічного турнірного використання потрібна додаткова серверна валідація всіх ігрових дій.
